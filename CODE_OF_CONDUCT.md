Code of Conduct

This repository is shared as a reference implementation for running Odoo in a production-grade Kubernetes environment.

The goal is to keep this project useful, professional, and welcoming for engineers who want to learn from it or improve it.

Be Professional
- Communicate respectfully and constructively.
- Assume good intent from other contributors.
- Keep discussions technical and solution-oriented.

What is Not Acceptable

- Harassment, discrimination, or personal attacks.
- Sharing private or sensitive information.
- Low-effort or disruptive contributions.

Maintainers

Maintainers may edit or remove contributions that do not follow these principles to keep the repository clean, useful, and professional.
